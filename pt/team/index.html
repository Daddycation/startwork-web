Como configurar a equipe

  1. Uma pessoa configura o StartWork: endereço do Jira, blocos para os seus tickets, arredondamento.
  2. Em Ajustes → Equipe → “Compartilhar modelo de equipe” surge um link – para o chat da equipe, por exemplo.
  3. Quem abre o link vê antes o que será aplicado, confirma e informa o próprio token. Pronto.

O que vai no link – e o que não vai

Vai: endereço do Jira, blocos (ticket, título, cliente, cor), arredondamento e se o refinamento por IA é permitido.

Não vai: token, e-mail, chave de IA, registros de trabalho. Se um link aponta para um endereço do Jira diferente do anterior, o StartWork apaga o token salvo – ele nunca vai para um endereço estranho.

Para a TI: distribuir pelo gerenciamento de dispositivos

Compre licenças em volume no Apple Business, em “Apps e Livros”, e atribua-as a dispositivos ou pessoas pelo gerenciamento de dispositivos (MDM).

Com a configuração de app gerenciada, você define dois valores para o StartWork:

teamTemplate
Link de um modelo de equipe (string). O StartWork o aplica ao abrir, sem perguntar – uma vez a cada mudança; depois, cada pessoa pode ajustar os próprios blocos.
disableAI
true (booleano) desativa o refinamento por IA. Ele não pode ser ativado no app, e nada é enviado à Anthropic.
<dict>
  <key>teamTemplate</key>
  <string>https://startwork.iamnotadev.xyz/pt/team/#v1.…</string>
  <key>disableAI</key>
  <true/>
</dict>

Cada pessoa informa o próprio token do Jira. Ele fica nas Chaves do sistema do iPhone e só vai para o seu Jira.
